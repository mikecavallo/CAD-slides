# Template for Tori: how to write a chapter so it builds in one pass

Write each slide like this in the Google Doc (or paste it in chat). Only Narration is required. Everything else is
optional: leave a line out and Claude designs that part and tells you what it chose.

```
## CH03,S01: Heading shown on the slide
On-screen text: Short words that should appear (a few lines at most)
Visual: What you want to see happen, in plain words, in order
Image: none / a file name already used / "attached" (send images in their own message)
Narration:
What you will say, exactly as you will record it.
```

Mark the end of the chapter with a line like `END CHAPTER 3 MATERIAL`.

Tips that save a round:
- One idea per paragraph of narration. A new paragraph is where the picture changes.
- If an animation must land on a word, say so: "when I say 'boils over', the pot spills".
- Name the photo if you want a real photo. Claude cannot download photos from stock sites.
- If you want the intro and agenda slides left out, say so. By default every chapter gets them.
